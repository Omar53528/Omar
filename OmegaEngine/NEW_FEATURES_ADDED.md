# Omega Engine - الميزات الجديدة المُضافة

## ✅ تم إضافة الميزات التالية بنجاح:

### 1. نظام الحزمة (Omega Packager) 📦
**الملفات:**
- `include/core/Packager.h` - النظام الأساسي
- `src/tools/PackagerTool.cpp` - أداة سطر الأوامر

**المميزات:**
- استخدام `std::filesystem` لاجتياز المجلدات تلقائياً
- تشفير XOR بسيط للحماية
- تحميل كسول (Lazy Loading) لتوفير الذاكرة
- تنسيق ملف `.opk` خاص بالمحرك

**الاستخدام:**
```bash
omega-pack.exe <source_dir> <output.opk>
```

### 2. نظام الجسيمات (Particle System) ✨
**الملفات:**
- `include/graphics/ParticleSystem.h`
- `src/graphics/ParticleSystem.cpp`

**المميزات:**
- دعم 2D و 3D
- فيزياء كاملة (جاذبية، سرعة، دوران)
- تدرج لوني وحجم ديناميكي
- دوال مخصصة للتحكم المتقدم
- إعادة استخدام الجسيمات لتوفير الذاكرة
